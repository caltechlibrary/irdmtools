# NAME

rdmutil-delete_endpoint - Perform a DELETE to the end point indicated by PATH.

# SYNOPSIS

rdmutil delete_endpoint PATH

# DESCRIPTION

Perform a DELETE to the end point indicated by PATH. PATH is required.
