# NAME

rdmutil-delete_files - Delete files in a draft record.

# SYNOPSIS

rdmutil delete_files RECORD_ID FILENAME [FILENAME ...]

# DESCRIPTION

Delete files in a draft record. RECORD_ID is required as are one or more
filenames.
