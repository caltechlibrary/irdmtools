# NAME

rdmutil-check_doi - This takes a DOI and searches the .pids.doi.identifiers for matching rdm records or drafts.

# SYNOPSIS

rdmutil check_doi DOI

# DESCRIPTION

This takes a DOI and searches the .pids.doi.identifiers for matching rdm
records or drafts. DOI is required.
