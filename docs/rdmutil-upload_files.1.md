# NAME

rdmutil-upload_files - Upload files to a draft record.

# SYNOPSIS

rdmutil upload_files RECORD_ID FILENAME [FILENAME ...]

# DESCRIPTION

Upload files to a draft record. RECORD_ID is required as are one or more
filenames.
