# NAME

rdmutil-harvest - harvest takes a JSON file containing a list of keys and harvests each record into the dataset...

# SYNOPSIS

rdmutil harvest KEY_JSON

# DESCRIPTION

harvest takes a JSON file containing a list of keys and harvests each record
into the dataset collection indicated by the environment variable C_NAME.
