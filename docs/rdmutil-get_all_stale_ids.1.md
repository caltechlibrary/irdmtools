# NAME

rdmutil-get_all_stale_ids - Returns a list of public record ids that are NOT the latest version of the records, useful when...

# SYNOPSIS

rdmutil get_all_stale_ids

# DESCRIPTION

Returns a list of public record ids that are NOT the latest version of the
records, useful when prune a dataset collection of stale RDM records.
