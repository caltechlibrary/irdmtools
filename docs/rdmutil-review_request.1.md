# NAME

rdmutil-review_request - Review a submitted draft record. the values "accept", "decline" or "" and an optional COMMENT.

# SYNOPSIS

rdmutil review_request RECORD_ID accept|decline|cancel|"" [COMMENT]

# DESCRIPTION

Review a submitted draft record. the values "accept", "decline" or ""
and an optional COMMENT.
