# NAME

rdmutil-send_to_community - Submit a draft record to a community for review.

# SYNOPSIS

rdmutil send_to_community RECORD_ID COMMUNITY_ID

# DESCRIPTION

Submit a draft record to a community for review. RECORD_ID and COMMUNITY_ID
are required.
