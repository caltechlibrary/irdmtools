# NAME

ep3util-get_modified_ids - Return a list of records created or modified in the START and END date range.

# SYNOPSIS

ep3util get_modified_ids START [END]

# DESCRIPTION

Return a list of records created or modified in the START and END date range. If END is not provided it is assume to be today.
