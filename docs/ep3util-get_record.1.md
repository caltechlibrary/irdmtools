# NAME

ep3util-get_record - Returns a specific simplified record indicated by RECORD_ID, e.g. 23808.

# SYNOPSIS

ep3util get_record RECORD_ID

# DESCRIPTION

Returns a specific simplified record indicated by RECORD_ID, e.g. 23808. The RECORD_ID is a required parameter.
