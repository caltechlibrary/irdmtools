# NAME

rdmutil-set_publication_date - This sets the publication date, .metadata.publication_date, in draft.

# SYNOPSIS

rdmutil set_publication_date RECORD_ID PUBICLATION_DATE

# DESCRIPTION

This sets the publication date, .metadata.publication_date, in draft.
RECORD_ID and PUBLICATION_DATE required. PUBLICATION_DATE can be in YYYY,
YYYY-MM, YYYY-MM-DD format.
