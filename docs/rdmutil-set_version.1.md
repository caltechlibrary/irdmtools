# NAME

rdmutil-set_version - This sets the version string in .metadata.version of a draft.

# SYNOPSIS

rdmutil set_version RECORD_ID VERSION_STRING

# DESCRIPTION

This sets the version string in .metadata.version of a draft. RECORD_ID and
VERSION_STRING are required.
