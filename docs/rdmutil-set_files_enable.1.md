# NAME

rdmutil-set_files_enable - This will flip the files.enabled value to true and update the draft.

# SYNOPSIS

rdmutil set_files_enable RECORD_ID true|false

# DESCRIPTION

This will flip the files.enabled value to true and update the draft.
RECORD_ID is required. The one of the values true or false are required.
