# NAME

rdmutil-get_draft_files - Retrieve the list of files attached to a draft.

# SYNOPSIS

rdmutil get_draft_files RECORD_ID

# DESCRIPTION

Retrieve the list of files attached to a draft. RECORD_ID is required.
